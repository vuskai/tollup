Tải file lên

File sẽ được lưu vào kho GitHub và xuất hiện ở trang tải về.

Trang tải về

Chỉ chủ kho mới có token nên chỉ bạn tải lên được. Token chỉ lưu trong trình duyệt của bạn.

Cách tạo token
  1. Vào GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: chọn đúng kho của bạn.
  3. Permissions → Contents: Read and write.
  4. Tạo token, sao chép và dán vào ô trên.
Kéo file vào đây hoặc bấm để chọn (tối đa 50 MB mỗi file)
    Sau khi tải lên, file hiện ngay ở trang tải về (không cần chờ GitHub Pages dựng lại).
